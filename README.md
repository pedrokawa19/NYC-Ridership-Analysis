# NYC Transit Ridership Analysis

This project analyzes New York City transit ridership alongside subway accidents and borough data. The analysis and visualizations are in `nyc_transit_ridership.ipynb`.

## Project Files

- `data/` contains the source and processed CSV files.
- `docs/` contains the project write-ups and presentation PDF.

## Run

Install the notebook dependencies:

```bash
python -m pip install jupyter pandas requests beautifulsoup4 matplotlib lxml
```

Open `nyc_transit_ridership.ipynb` in Jupyter and run the cells from top to bottom. Some cells fetch data from public websites and APIs, so an internet connection is required.
